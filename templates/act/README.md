# Рабочий шаблон

Контракт всех полей, источников и повторения строки: [TEMPLATE_CONTRACT.md](../../TEMPLATE_CONTRACT.md).

`акт_рабочий.docx` — адаптированная копия оригинала из корня проекта. `example-input.json` — вымышленные данные, показывающие границу между реквизитами акта и сведениями из БД. Это пример входа генератора, не формат HTTP-запроса: браузер передаёт только реквизиты акта, ID и версии записей.

Ожидаемый результат — акт с одной строкой на устройство, полной стоимостью и НДС, общим итогом и сохранёнными подписями. Файлы результатов помещаются в `output/`; приложение отдаёт документ напрямую для скачивания. Шаблон встроен в сервер; после правок нужна пересборка.
