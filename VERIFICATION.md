# Проверка примера Word-шаблона 29.09.2026

Получен `акт_шаблон.docx` в корне проекта. Исходник не изменялся; пробные файлы находятся в `output/`. Контрольная копия исходника имеет SHA-256 `6AF06B2D67B5FFCA731E0ADAE16EFC168EAC2F959A43A10731EB6218D580FB5D`.

В шаблоне семь маркеров: `DATE`, `NAME`, `INV`, `SN`, `COUNT`, `PRICE`, `COMMON_PRICE`. Все записаны как `{{...}}`; маркер даты дополнительно разбит Word на два текстовых фрагмента. `go-docx` v0.5.0 отверг двойные скобки как вложенные маркеры. В рабочей копии из `output/` они преобразованы в одинарные; исходный файл сохранён. После этого `go-docx` заменил все семь маркеров, включая дату и значения с кириллицей, `&` и `<`.

`output/акт-пробный.docx`: ZIP и XML проверены; незаполненных маркеров нет. Microsoft Word открыл файл и экспортировал одну страницу в PDF. Изображение страницы просмотрено: короткий пример умещается и оформление шаблона сохранилось.

Выявленные ограничения: в таблице исходника только одна строка оборудования; API `go-docx` не повторяет строку. Проба с длинным наименованием и полной фразой о НДС показала обрезание текста на границе ячейки. Для акта с несколькими устройствами и произвольными данными нужен согласованный вариант шаблона с правилом добавления строк и достаточной шириной/высотой для длинных значений. До этого маршрут скачивания Word на сайте остаётся недоступным.
